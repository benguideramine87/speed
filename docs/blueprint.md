# **App Name**: Safarna

## Core Features:

- Flight Booking: Allow users to search for and book flights.
- Hotel Booking: Enable users to search for and book hotels.
- Transfer Booking: Allow users to book transfers between airports and hotels.
- AI-Powered Travel Recommendations: Suggest destinations and activities based on user preferences using a tool that uses an LLM for planning.
- User Account Management: Allow users to create and manage their accounts, store travel preferences and booking history.
- Payment Processing: Enable secure payment processing for bookings.

## Style Guidelines:

- Primary color: Light, airy blue (#72BCD4), reminiscent of sky and open spaces.
- Background color: Off-white (#F5F5F5), providing a clean, uncluttered backdrop.
- Accent color: Soft yellow (#FFECB3) to highlight important actions and elements.
- Body and headline font: 'PT Sans', a humanist sans-serif font for readability and a touch of warmth.
- Use clear and recognizable icons to represent different travel services and options.
- A clean, modern layout with intuitive navigation to guide users through the booking process.
- Subtle transitions and animations to enhance user experience and provide visual feedback.
